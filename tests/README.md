# Tests

This directory contains requirement-driven tests for the reference validator.

The validator fixture metadata lives under [../validator/fixtures](../validator/fixtures). Valid examples are copied from [../examples](../examples), and invalid inputs are generated by applying targeted mutations during the test run.

Run the test suite:

```powershell
python -m unittest discover -s tests -p "test_*.py"
```

The traceability tests require every automated archive/content or processing requirement to have rule coverage and expected-finding fixture coverage. Reader, writer, and privacy behavior remains separately scoped.

`validator/test_v1.py` adds 1.0 boundary and behavior checks: ZIP64 end records, bounded reads, unknown data, version dispatch, URI/date/numeric validation, safe extras, private-value diagnostics, no network/rendering/extraction, and source-byte preservation. The candidate writer is exercised with an actual archive and overwrite refusal.

The fixture harness writes only into temporary test directories. No application collection or third-party implementation is tested. These checks are not a claim of safe extraction by an application, full lossless preservation, or independent interoperability. See the [verification scope](../README.md#verification).

The suite also includes the exact 65,537-byte Deflate/trailing-garbage regression (including a timeout-protected public API check), clean chunk boundaries, legacy BZIP2 versus 1.0 dispatch, bounded root probing, and unsupported root codec/no-payload-read checks.
